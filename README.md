# ALMA

Мобильный web-прототип персональной системы наблюдения и интерпретации состояния во времени.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Что уже работает

- большой цикл-лотос, настройка даты начала, длины цикла и менструации;
- отдельные бусины менструации, фертильного окна и расчётной овуляции;
- интегральная субъективная волна: факт слева, сегодня в центре, бледный прогноз справа;
- переключение внутренних волн и внешних контекстных слоёв;
- шкалы мозга, сердца, тела, либидо и социального фона от −100 через нейтральный 0 до +100;
- подтверждение, отклонение, интенсивность и добавление симптомов;
- карточка выбранного дня и режим визуального сравнения связей;
- реальные температура, давление, влажность, ветер и световой день из Open-Meteo;
- реальный планетарный Kp из NOAA SWPC;
- локальное сохранение с готовой безопасной синхронизацией Supabase.

## Supabase

Схема уже применена к подключённому проекту и сохранена в `supabase/migrations`. Все таблицы ALMA имеют префикс `alma_`, включённый RLS и доступ только к строкам текущего пользователя.

Для бесшовной облачной синхронизации без экрана регистрации включите в Supabase: **Authentication → Providers → Anonymous Sign-Ins**. Пока настройка выключена, приложение честно показывает «на устройстве» и сохраняет весь ввод в `localStorage`; после включения кнопка статуса переносит сохранённую историю в облако.

This is an observation tool, not a diagnostic or treatment product.

# Contact Engine

## Задача

ALMA не должна конкурировать за внимание сразу всеми возможными вопросами и выводами. Contact Engine объединяет Input Requests и Output Feed в небольшой attention budget.

## Приоритет

Для input учитываются information value, urgency, research relevance, uncertainty reduction и effort. Для output — новизна, персональная значимость, maturity evidence, actionability и read state.

## Progressive disclosure

- сначала один наиболее полезный вопрос или один новый смысл;
- дополнительные элементы — только по желанию;
- пропущенный субъективный вопрос истекает;
- unread полезный insight не исчезает только из-за возраста;
- после информативного ввода ALMA объясняет, что именно изменилось.

Input и Output остаются быстро доступны при скролле, но внутренние engines не превращаются в десятки равноправных вкладок.

# Narrative Engine

## Structured first

Core создаёт `StructuredInsight`, а deterministic Narrative Engine превращает его в ru-RU текст по versioned templates. Числа, тип связи, lag, cumulative window, modifiers и evidence references остаются структурированными.

## Пользовательский язык

Допустимые формулировки:

- «В ваших наблюдениях головная боль чаще появлялась в дни с…»;
- «Связь становилась заметнее, когда…»;
- «Эта закономерность пока возможная — наблюдений ещё немного»;
- «В последнее время прежняя связь повторяется реже».

Недопустимы диагноз, назначение лечения и причинное «X вызывает Y». Технические названия algorithm/version не выводятся как основной текст.

## Immutable output

Уже доставленный feed item не переписывается. Если evidence изменился после исправления или удаления, создаётся новый refinement/correction item со ссылкой на прежний.

## LLM boundary

Runtime LLM сейчас отсутствует. В будущем он может предложить перефразирование или разобрать голосовой текст, но только поверх structured result; факты и статусы подтверждает человек, а deterministic template остаётся fallback.
